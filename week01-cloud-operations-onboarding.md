# Week 1: Cloud Operations Onboarding

## HarborTech Ticket Summary
HarborTech wanted interns to demonstrate readiness by showing that the tools within AWS were accessible and that they understood AWS Learner Lab boundaries, and to ensure that we can document readiness issues without guessing or bypassing controls

## Client Impact
Environment readiness matters because if an intern helping a customer create resources can't navigate, access, or create them, the customer may lose confidence in us and choose not to work with us again. It also lets us see what caused the issue and learn from it. 

## AWS Services Involved
AWS Academy provides learning modules; Learner Lab creates a sandbox environment to access, create, and maintain resources; and IAM provides the user role lab_role for this instance, which allows resource creation. Regions provide faster response times when creating or deleting resources. For the account, we use our own personal account to secure and manage resources through the course materials. The documentation concepts consist of managing and understanding readiness basics for AWS Academy.
## Virtualization Connection
Software-defined cloud infrastructure still depends on accounts by allowing selected accounts to view, manage, and create resources safely within the work environment. For regions, it ensures users can create resources in fast, reliable regions, with costs depending on how many instances a person creates and other cloud usage. With platform boundaries, AWS Learner Lab will not allow a learner account to create or configure certain settings that violate AWS policies.

## Professional Vocabulary
Define the important Week 1 terms in your own words.
Include terms such as:
- Virtualization - A way to use physical hardware as software, while not being in direct control of the physical hardware.
- Evidence - To provide a verifiable log of a configuration process that has results and exact documented steps.
- Finding - A way to access information and document what we currently see.
- Assumption - Something that we accept as true without providing immediate proof or evidence.
- Escalation - Moving an issue to someone with higher authority and the correct skills and expertise.
- Sandbox - A configurable environment to simulate a real task.
- Region - A Way to provide availability from multiple zones to provide access.
- IAM - Configurable permissions for an account to allow or deny actions to create resources.
- Operations Playbook - Documented step-by-step procedure to provide all essentials when it comes to creating a resource and a way to provide evidence of the project's completion.
